# Stage 3 path after the second review

18 октября 2026. Stage 2 и пакет G1 не изменялись. Массовый пилот не разрешён. E0 не пройден.

## Guards на пути исполнения

`stage3/pipeline.py` — единственная точка попытки Stage 3. До вызова transport она требует снимок ledger и допускает только модель из allowlist Stage 0. `qwen/qwen3-32b` и `deepseek/deepseek-v4.1-flash` до transport не доходят. Запрос собирается из явных `model_id` и `seed`, не из `next(iter(models))`. После ответа статус выводится из сырого тела; заявленный `failed` на завершённой трассе отвергается.

`accept_embeddings` вызывает `align_embeddings` с режимом Local или Contextual. Для Contextual хеш считается от полного входа: до двух предыдущих сегментов, не длиннее 1000 символов, плюс текст текущего сегмента. Хеш одного только `row["text"]` для контекстного вектора отвергается.

## Диагностическая сложность

Список v2 не отменён. Аудит `stage3/baseline_audit.py` на его задачах: точность большинства по семейству для не-математических задач равна 1; baseline «всегда UNSAT» на логике равен 0.66.

Дополнение `design/PILOT_SECTION_5_5_ROSTER_V3.json` — development-корпус, не замена v2 и не разрешение массового пилота. Внутри каждого семейства логики, алгоритмов и планирования есть оба исхода. На этом списке точность большинства по семейству 0.52, baseline «всегда UNSAT» 0.48. У математики easy не содержит умножения, а hard добавляет модуль или сдвиг. 200 разных roots по-прежнему лежат в 12 семействах генерации: это вариативность экземпляров, не 200 новых постановок.

Платные вызовы и человеческий эталон E0 этим файлом не выполняются.
