# Правила агента

Рабочее пространство исследования Reasoning Universalis. Научные гипотезы живут в `RESEARCH_SPECIFICATION.md`; этот файл задаёт, как агент действует.

## Харнес

Cursor — единственный агентный харнес. Не создавать отдельных LLM-агентов для сегментации, анализа, рецензирования или написания статьи. Лексические и статистические бейзлайны без дополнительных LLM допустимы.

## Модели

Кандидаты эксперимента, и только если у вызова есть настоящая полная reasoning trace:

- Qwen3-8B (`qwen/qwen3-8b`)
- Qwen3.8-27B (`qwen/qwen3.8-27b`)
- GPT-OSS-20B (`openai/gpt-oss-20b`)
- Muse Glimmer-30B (`meta/muse-glimmer-30b`)
- Gemma4-31B (`google/gemma-4-31b-it`)
- Nemotron 3 Nano 30B A3B (`nvidia/nemotron-3-nano-30b-a3b`)

Включение модели зависит от реальной полной трассы. Если трассы нет, это фиксируется в отчёте. Восстанавливать трассу из итогового ответа нельзя.

Эмбеддеры только два: BGE-M3 (`baai/bge-m3`, 1024) и Qwen3-Embedding-8B (`qwen/qwen3-embedding-8b`, до 4096).

Все экспериментальные вызовы моделей и эмбеддеров идут через RouterAI (`ROUTERAI_BASE_URL=https://routerai.ru/api/v1`). RouterAI — внешняя инфраструктура, не часть открытой реализации.

Код, данные и методы исследования остаются открытыми и воспроизводимыми. Перед включением модели проверять лицензию. Nemotron — NVIDIA Open Model License.

## EpistemeOS и протокол

EpistemeOS используется для протоколов, провенанса, экспериментов, статистического вывода и аудита. Исходники, тесты, `README.md` и `AGENTS.md` внутри `EpistemeOS/` не переписывать попутно.

Научную спецификацию не переписывать: гипотезы сохраняются, операционные уточнения только дописываются.

Этап 0 (строгая загрузка `.env`, пробы моделей и эмбеддеров, пилот на 5–10 задач) ещё не выполнен и этим харнесом не запускается. Основное исследование ждёт завершения пилота и замороженного протокола.

Секрет `ROUTERAI_API_KEY` не читать в коммиты, логи и артефакты. Файл `.env` не коммитить.

## Cursor Cloud specific instructions

- Облачная среда — Ubuntu VM.
- Скрипт установки из корня репозитория запускает `uv` (см. `.cursor/environment.json`): установка `uv`, Python 3.12, затем `cd EpistemeOS && uv sync --frozen`.
- Тесты лежат в `EpistemeOS`.
- RouterAI не вызывать, пока не начат этап 0. `ROUTERAI_API_KEY` не печатать.
- `.env` только для локальной машины. В Cloud ключ берётся из секретов Cursor, не из git.
- Научную спецификацию не переписывать.
