# Доказательства исторического Stage 0

`stage0-2026-10-12.zip` — переносимый экспорт реальных артефактов от 12 октября 2026. Пакет предназначен для проверки отчётных чисел без API, ключей и локального `.research`. Проверяющий использует Python ≥ 3.11 из корня репозитория:

```powershell
python -m stage0.evidence --verify evidence/stage0-2026-10-12.zip
```

В ZIP сохранены запросы, ответы, контексты, исходный технический review, бюджетный журнал и billing receipts. `manifest.json` содержит hashes экспортированных файлов и соответствующих оригинальных локальных артефактов. HTTP headers удалены, локальные пути заменены, JSON заново сериализован; hashes оригиналов нельзя проверять по преобразованным байтам. Каталог моделей, endpoint metadata и исходники исторического запуска остаются в исходном checkout и локальном архиве; экспорт содержит git commit и hashes исходников в context.

Полноту исходного HTTP-тела в байтах для исторического запуска восстановить нельзя: старый transport сохранял декодированный текст. Пакет подтверждает пересчёт сохранённых данных, а не подлинность ответа внешнего сервиса или научную валидность.

Ожидаемый пересчёт: 32 попытки, 6/6 ответов, 105 сегментов, 210 векторов; идентичность проходит для 175 векторов. Остальные 35 вернулись как `parasail-bge-m3` и исключены из строгого допуска.
