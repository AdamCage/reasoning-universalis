# Машинная разметка: подготовка v0.2

Пользователь выбрал **только ансамбль `deepseek/deepseek-v4.1-flash`**, 3–5 голосов с фиксированными seeds и повтором через новые seeds при отсутствии большинства. Человеческая валидация отложена; **E0 не пройден**. Это явное исключение из прежнего запрета дополнительных LLM-разметчиков. Оно относится к разметке; отдельные LLM для научной рецензии, анализа, сегментации или написания статьи этим не разрешены.

Вызовы одной модели с разными seeds являются одним ансамблевым измерителем, а не независимыми человеческими экспертами или разными модельными семействами. Согласие голосов измеряет его внутреннюю согласованность. Общая систематическая ошибка может сохраниться при единогласии. Фиксированный seed не доказывает детерминизм внешнего исполнения; воспроизводимость должна включать сохранённые ответы, неизменные входы, версию модели/маршрут и отдельную проверку повторяемости.

## Cluster-first

Сначала построить состояния на development без целевых семей и закрытых roots; число кластеров и метод выбирать внутри development. Затем интерпретировать их функционально. Исходные восемь ролей §3 — ориентир для сопоставления, не требование получить ровно восемь кластеров. Онтология получает revision/digest; соответствия «кластер → роль» замораживаются до независимой оценки. Нельзя максимально выравнивать кластеры на test и считать достигнутое сходство доказательством переноса.

Машинная интерпретация development-кластеров и машинная разметка отдельных сегментов должны иметь разные prompt revisions и provenance. В пакет сегментной разметки не включать автоматическую cluster label, модель-генератор, provider, correctness, gold answer, split или исходную оценку других голосов. Иначе согласие становится самоподтверждением кластеризации. Контекст фиксирован: условие без gold answer, сегмент, максимум два предшествующих сегмента; расширение контекста только отдельной измерительной конфигурацией. Схема допустимых ролей берётся из выбранной development-онтологии.

## Конечное голосование — предлагаемые технические детали

Для облачного агента предлагается панель из **5** вызовов, большинство **3/5**, максимум **2** раунда. Эти числа уточняют заданный диапазон 3–5 и требуют фиксации в протоколе Stage 1; они не приписываются уже состоявшемуся выбору пользователя. Альтернатива: отдельная заранее заданная конфигурация 3 голоса, большинство 2/3. Менять размер панели по удобному результату запрещено.

Первый раунд использует seeds из неизменного schedule, второй — другой заранее заданный schedule. Каждый голос не видит остальные. Если первый раунд не дал большинства, сохранить все его результаты и выполнить второй полный раунд; не повторять запросы до получения удобной метки. После второго отсутствия большинства — `ambiguous/unresolved`. Для сводной метки предлагается использовать большинство выбранного раунда, не смешивая раунды задним числом. Всегда показывать распределение первого раунда, частоту повторов, resolved/unresolved и чувствительность результатов к правилу объединения.

HTTP/API-ошибка, неверная модель/provider, невалидная структура и обрезанный ответ не считаются голосом роли. Такие попытки сохраняются и расходуют резерв; порядок действий при неполной панели должен быть зафиксирован до запуска. Ошибочные попытки не запускают бесконечные автоматические retries. Полнота панели и допустимость повторного раунда различаются: отсутствующие ответы не являются семантическим разногласием.

Сохранять для каждой попытки model/requested/returned/provider/revision, seed requested и доступное подтверждение исполнения, prompt/ontology/context/segment hashes, HTTP/API status, raw bytes, parsed label, stop reason, usage/billing, budget reservation, номер панели/раунда/голоса. Результат API с неустановленным применением seed нельзя называть воспроизведённым по seed. Смена маршрута — новый измерительный режим с отдельной проверкой. Совпадение seed не создаёт новую независимую репликацию.

## Ограничения допуска

DeepSeek здесь — кандидат **измерителя**, отдельно от его возможной роли генератора исследуемых трасс. Лицензию и реальное доступное условие RouterAI проверить до будущих вызовов. Совпадение генератора и разметчика создаёт возможный bias; сообщать результаты по семьям и отдельно для DeepSeek-generated traces, проверять альтернативные измерители. Seed ensemble одной линии не заменяет другой эмбеддер или человеческий эталон.

`human_cohen_kappa_primary` и true macro-F1 относительно человеческого эталона из E0 v0.1 пока **not evaluated**. Kappa между машинными голосами маркируется machine agreement, F1 относительно агрегированного решения — agreement with consensus. Голоса не превращаются в ground truth и не позволяют объявить measurement validity или scientifically approved claim. Предварительные E0 targets сохраняются для будущей независимой валидации, а не переименовываются в пороги машинного согласия.

Текущий локальный этап готовит документы. Облачный Stage 1 оформляет дизайн, prompt/schema/seed schedule и план затрат; это не разрешение начать платную разметку, допуск всей когорты, научный пилот или confirmatory-сбор.
