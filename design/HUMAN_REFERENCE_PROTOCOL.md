# Независимый human-reference protocol для E0

Статус: протокол подготовлен, разметка не выполнена. E0 не пройден.

Этот набор не является человеческим gold. Синтетические фразы в `HUMAN_REFERENCE_ITEMS.json` — воспроизводимый пакет для будущих аннотаторов. Ключ constructed-control хранится отдельно и не показывается аннотатору.

## Кто размечает

Два человека, не автор автоматического сегментатора в момент разметки. Они не видят имя модели, provider, правильность ответа, split и метку кластера. Модель не заменяет ни одного из двух людей.

## Что видит аннотатор

`item_id`, текст сегмента и два предыдущих сегмента, не длиннее 1000 символов. Определения ролей берутся из `design/ANNOTATION_PROTOCOL.md`: planning, deduction_computation, verification, conclusion, и остальные классы того словаря, включая `ambiguous_other`.

## Что записывает аннотатор

`primary_role`, `secondary_roles`, `confidence`, `reason_code`, `context_extended`. Файл каждого аннотатора хранится отдельно. Согласие считается до adjudication. Пока второго файла нет, kappa не вычисляется и не подменяется.

## Adjudication

Третий человек разбирает расхождения после того, как обе независимые разметки сданы. До этого gold-файл остаётся `not_annotated`.

## Что не делается этим протоколом

Не объявляется порог успешности E0. Не переносятся машинные голоса DeepSeek в gold. Не используется confirmatory-корпус.
