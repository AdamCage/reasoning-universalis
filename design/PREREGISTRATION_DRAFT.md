# Черновик preregistration v0.1

Работа исследует уровни A (перенос функциональных ролей) и B (динамическая организация наблюдаемых текстовых трасс). Уровень C внутренней причинной организации не устанавливается. Видимый reasoning, скрытые активации, вычислительные зависимости генерации и последующее объяснение — разные объекты. Импорт разрешён только из явного reasoning-канала; финальный ответ не преобразуется в трассу.

Неизменные формулировки H0–H7, поддержка и опровержение берутся из §3 [спецификации](../RESEARCH_SPECIFICATION.md). Машинно-читаемый снимок этих секций с hashes создаётся в `design/hypotheses.json`; он копирует источник, не редактирует его. H0 не доказывает происхождение общности из обучающих данных при ненаблюдаемых корпусах.

Для каждой H0–H7 в снимке присутствуют поля §11.2: primary metric, direction, null model, effect size, confidence interval, significance plan, multiple-testing family, minimally meaningful effect, insufficient-power criterion. Их окончательные значения **не заданы спецификацией; решение отложено до заморозки протокола**. Holm остаётся примером. Ниже предложения для разработки, не выбранные confirmatory-тесты:

| Гипотеза | Development-кандидат измерения | Контроль/ограничение |
|---|---|---|
| H1 | Macro-F1 переноса восьми ролей и по-классовые ошибки | Лексический baseline, новые семьи/задачи, несколько измерителей |
| H2 | Held-out прогноз перехода и сходство поддержанных рёбер | Частоты, позиционный профиль, matched объём, нулевые модели |
| H3 | Различия переходов и длительностей, воспроизводимые на новых задачах | Домен/сложность, provider, ошибка меток |
| H4 | Динамическое сходство успешных траекторий | Информативные task roots со смешанными исходами |
| H5 | Изменение вероятности корректного завершения префикса | Повторные probes, утечка ответа, неоднозначность извлечения |
| H6 | Различие условий масштаба внутри сопоставимой линии | Наблюдательное сравнение, версия/обучение/provider confounding |
| H7 | Добавочная предсказательная ценность и accuracy/cost | Baselines длины/позиции/текста, одинаковый риск, фактическая остановка |
| H0 | Практически малый остаточный эффект после сильных контролей | Валидный измеритель, достаточная точность; незнание причины не заменено причинным выводом |

Предварительные критерии E0 вынесены отдельно и служат качеству **измерителя**, не научным effect sizes H1–H7. Их инженерные значения не превращаются в финальные пороги без отдельной фиксации и независимой оценки.

Независимая единица анализа — задача или независимый root, не сегмент и не повтор той же задачи. Генерации вложены в задачу; family holdout не заменяет task holdout. Измерительная ошибка оценивается отдельно и распространяется на динамические выводы.

Осторожное утверждение об универсальности требует совместно: переноса на невиденные семьи; воспроизводимой динамической структуры; устойчивости к измерителю; превосходства над языком/длиной/позицией; независимых новых задач; интервалов, исключающих заранее выбранную область практически незначимого эффекта (§11.4). Частичное выполнение означает более узкий вывод.

## Самостоятельный DomainPack

`reasoning_universalis_v1` проектируется отдельно от демонстрационного `risen_universalis_v1`. Планируемый контракт с EpistemeOS: canonical raw/metrics schemas, binding dataset/task/splits/method/protocol/run/response, импорт как external evidence при RouterAI, неизменяемые parent artifacts, управляемые анализ/review/claims. Внешнее API-исполнение не становится локальным managed execution. Существующий registry и исходники EpistemeOS не изменяются. Текущий `measurement/` — development-библиотека, ещё не зарегистрированный DomainPack; контрактные тесты §13.8 и адаптер остаются отдельной работой.

G1: `status=pending`, имя утвердившего и hash утверждённого состояния отсутствуют. Это честный черновик, не фиктивная запись приёмки. G2/G3/G4 также не выполнены. Разрешение разрабатывать следующий этап не подменяет утверждение конкретного preregistration и финального протокола.
